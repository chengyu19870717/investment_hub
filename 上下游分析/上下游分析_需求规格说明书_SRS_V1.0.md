## 1. 引言

### 1.1 目的

本规格说明书旨在完整定义"上下游分析"功能模块的产品需求，作为后续设计、开发、测试和验收的基准依据。本文档供项目经理、开发团队、测试团队和质量保障人员共同使用。

### 1.2 范围

- **所属产品**：程钰的百宝箱
- **开发技术**：Claude Code + Codex
- **目标用户**：个人投资者、行业研究者

### 1.3 定义与缩略语

| 术语 | 定义 |
|------|------|
| 产业链 | 从原材料获取到最终产品交付使用的完整价值链条 |
| 核心工艺 | 在产业链某一环节中起决定性作用的关键制造/加工工序 |
| 供需格局 | 某一环节的供给能力与市场需求之间的平衡状态 |

| 实体清单 | 美国商务部工业与安全局（BIS）发布的出口管制受限实体名单 |

## 2. 总体描述

### 2.1 产品背景与目标

"程钰的百宝箱"是一个个人投资者的综合工具平台，本模块作为产业链认知工具，帮助用户快速理解算力、脑机接口、航空航天三大行业的上下游关系，识别产业链中的关键节点和投资机会。

### 2.2 产品定位

| 维度 | 说明 |
|------|------|
| 产品定位 | 产业链认知工具 + 投资辅助面板 |
| 核心价值 | 解决"这个公司卡在哪一环/我持仓的上游是谁下游是谁" |
| 用户画像 | 有一定投资经验的个人投资者，关注科技和高端制造赛道 |

### 2.3 观测行业

| 行业名称 | 产业链范围 | 节点数估算 |
|---------|---------|---------|
| **算力** | AI芯片→服务器→数据中心→云服务/AI应用 | ~8-12个节点 |
| **脑机接口** | 核心材料→零部件→BCI设备→医疗/消费应用 | ~6-10个节点 |
| **航空航天** | 原材料→关键零部件→总装→卫星/火箭/无人机→运营 | ~8-12个节点 |

### 2.4 用户使用场景

| 场景 | 描述 |
|------|------|
| 场景A | 用户研究某只股票，想知道它在产业链中的位置和上下游关系 |
| 场景B | 用户看到新闻说"某芯片断供"，想快速找到哪些上市公司受影响 |
| 场景C | 用户想找某个细分赛道里的优质标的，通过产业链树状图浏览 |
| 场景D | 用户想对比同一环节不同上市公司的业务纯度和护城河 |

### 2.5 设计与约束

- 技术栈：由 Claude Code + Codex 开发团队自行决定
- 数据来源：公开信息为主（上市公司公告、工信部文件、行业协会报告）
- 无需用户注册/登录
- 优先Web端，移动端基础适配

### 3.2 FR-001 行业切换

**功能描述**：用户可在三个行业（算力、脑机接口、航空航天）之间切换，查看对应行业的产业链结构。

**前置条件**：无

**基本流程**：

1. 用户点击行业标签栏中的某一行业
2. 系统切换至该行业的产业链树状图
3. 页面自动定位至该行业的上游层起点

**交互规格**：

- 行业标签栏固定在页面顶部
- 当前选中行业高亮显示（激活态样式）
- 切换动画：淡入淡出，切换时长 ≤ 1秒

**异常处理**：

- 网络异常：显示"数据加载失败，请重试"，保留重试按钮
- 行业数据缺失：显示"该行业数据暂未收录"，不跳转

### 3.3 FR-002 产业链树状图展示

**功能描述**：以树状层级图展示产业链上中下游关系，每层节点包含核心产品/核心工艺标注。

**前置条件**：已选择某一行业

**基本流程**：

1. 系统从数据源读取该行业的产业链结构
2. 按上游→中游→下游三层渲染树状图
3. 各节点之间连线表示依赖关系（箭头指向被依赖方）
4. 节点按规模/重要性纵向排列

**节点展示规格**：

每个节点包含以下信息：
- **节点名称**：核心产品或核心工艺名称
- **节点类型**：`原材料` | `零部件` | `核心产品` | `核心工艺` | `终端产品` | `运营维护`
- **供需格局标签**：宽松 / 偏紧 / 断供风险（如已配置）
- **持仓股高亮**：若该节点包含用户持仓股，节点边框高亮显示（如已配置）

**节点布局规则**：
- 横向：左→右 = 上游→下游
- 纵向：按规模/重要性从上到下排列
- 同层节点数量不限
- 连接线样式：带箭头实线，颜色深浅表示依赖强度

**视图切换**：
- 支持切换为桑基图视图（见 FR-006）
- 切换按钮位于页面右上角，图标为切换图标

**异常处理**：
- 产业链结构数据为空：该行业显示"数据正在构建中"

### 3.4 FR-003 节点详情展开

**功能描述**：用户点击树状图中的某一节点，展开该节点的详情面板。

**前置条件**：用户已点击产业链树状图中的某一节点

**详情面板内容**：

| 信息类别 | 内容项 | 数据来源 |
|---------|-------|---------|
| 基本信息 | 节点名称、类型、说明 | 产业链数据库 |
| 核心产品 | 该节点对应的核心产品清单 | 产业链数据库 |
| 核心工艺 | 该节点对应的核心工艺/工序 | 产业链数据库 |
| 供需格局 | 国产替代率、产能瓶颈等级、关键原材料价格 | 工信部/行业协会 |
| TOP5企业 | 对应头部上市企业列表（含财务纯度、专利标注） | 年报/招股书 |
| 政策风险 | 制裁状态、专精特新资质、大基金持仓 | BIS/工信部 |
| 持仓关联 | 持仓股是否在此节点、高亮标注 | 用户输入数据 |

**面板交互规格**：
- 展开方式：从节点右侧滑出，或居中弹窗
- 面板关闭：点击遮罩层或关闭按钮
- 面板内部滚动：内容超出一屏时可滚动

### 3.5 FR-004 TOP5企业列表

**功能描述**：每个节点对应列出该环节的头部上市企业 TOP 5，不足5家照实显示。

**企业卡片内容**：

| 字段 | 说明 | 格式 |
|------|------|------|
| 股票代码 | 上交所/深交所代码 | 600XXX / 000XXX 等 |
| 公司简称 | 简称 | 文本 |
| 上市板块 | 沪市主板/科创板/深市主板/创业板 | 文本 |
| 核心产品/工艺 | 该企业在此环节提供的产品或工艺 | 文本 |
| 营收占比 | 该业务占总营收比例 | 百分比，如"78%" |
| 毛利率 | 该业务毛利率 | 百分比，如"42.5%" |
| 客户集中度 | 前五大客户占比 | 百分比，如"35%" |
| 专利标记 | 是否持有核心专利 | 🔬 标记（有）/ 无标注 |
| 制裁状态 | 是否在实体清单 | 红色预警标签 / 无标注 |
| 资质标注 | 专精特新/小巨人/大基金持仓 | 资质标签 |

**交互规格**：
- 默认显示前5家
- 企业数量<5时：照实显示，底部显示"该环节目前收录X家企业"
- 点击企业卡片：跳转至该企业详情页（见 FR-DETAIL）

**数据规则**：
- 营收占比数据滞后一个季度（以最新年报为准）
- 毛利率为该业务单独毛利率，若年报未披露则标注"未披露"
- 客户集中度为年报中"前五大客户占比"数据
- 无数据的字段显示"—"，并标注"数据暂未收录"

### 3.6 FR-005 专利标注

**功能描述**：持有核心专利的企业在企业卡片和节点中有特殊标注。

**专利来源**：
- 国家知识产权局公开数据库
- 上市公司年报/招股书"专利情况"章节

**标注规则**：

| 专利情况 | 标注方式 | 优先级 |
|---------|---------|-------|
| 持有与本节点相关核心发明专利≥5件 | 🔬 标记 + 标注专利数量 | 高 |
| 持有与本节点相关实用新型专利≥10件 | 🔬 标记（灰色） | 中 |
| 持有相关专利但数量较少 | 无特殊标记，详情页可见 | 低 |
| 无相关专利 | 无标注 | — |

**展示位置**：
- 企业卡片：股票名称右侧
- 详情面板：专利信息区块
- 树状图节点：节点右下角

### 3.7 FR-006 桑基图视图切换

**功能描述**：提供桑基图视图，用于可视化上下游之间的流量/依赖关系方向。

**前置条件**：已加载产业链树状图

**桑基图规格**：
- 左列：上游各节点（原材料/元器件）
- 中列：中游各节点（核心产品/工艺）
- 右列：下游各节点（终端产品/运营）
- 流量线条宽度：与依赖强度成正比
- 颜色：上游→中游用蓝色系，中游→下游用橙色系

**切换规格**：
- 切换按钮位于页面右上角
- 点击切换：当前视图淡出 → 目标视图淡入
- 切换时长 ≤ 1秒
- 桑基图模式下不支持节点详情展开（需切回树状图）

### 3.8 FR-007 供需格局标注

**功能描述**：在产业链各节点标注供需格局信息。

**标注内容**：

| 指标 | 说明 | 示例 |
|------|------|------|
| 国产替代率 | 该环节国内产能占全球总需求的百分比 | "国产替代率：18%" |
| 产能瓶颈等级 | 当前产能是否能满足需求 | 宽松 / 偏紧 / **断供风险** |
| 关键原材料价格 | 当前主要原材料市场价格 | "H100：$25,000/片" |

**标注样式**：

| 产能瓶颈等级 | 颜色标签 | 含义 |
|-------------|---------|------|
| 宽松 | 绿色 | 供给充足，价格稳定 |
| 偏紧 | 黄色 | 供给偏紧，价格有上涨压力 |
| 断供风险 | **红色** | 存在断供风险，价格大幅波动 |

**数据来源**：工信部、中国半导体行业协会、中国碳纤维协会、WIND、生意社

**更新频率**：
- 国产替代率：半年更新
- 产能瓶颈等级：季度更新
- 原材料价格：周频更新

### 3.9 FR-008 财务纯度标注

**功能描述**：在 TOP5 企业列表中标注各企业的业务纯度指标。

**标注内容**：

| 指标 | 计算方式 | 判读参考 |
|------|---------|---------|
| 营收占比 | 该业务营收 / 公司总营收 | >70%为主业，<30%为蹭概念 |
| 毛利率 | 该业务毛利 / 该业务营收 | >40%为强护城河，<20%为低壁垒 |
| 客户集中度 | 前五大客户营收 / 总营收 | >50%风险高，<30%为健康 |

**业务纯度评级**：

| 营收占比 | 毛利率 | 评级 | 标签颜色 |
|---------|-------|------|---------|
| >70% | >40% | 主业+强护城河 | 🟢 深绿 |
| >70% | 20-40% | 主业 | 🟢 浅绿 |
| 30-70% | >40% | 多元化+强护城河 | 🟡 黄色 |
| 30-70% | 20-40% | 多元化 | 🟡 浅黄 |
| <30% | 任何 | ⚠️ 蹭概念 | 🔴 红色 |

**展示规格**：
- 每个企业卡片底部显示三个指标数值
- 综合评级标签显示在企业卡片右上角
- 详情面板中显示详细数据表格

### 3.11 FR-010 持仓股高亮

**功能描述**：自动识别用户持仓股在产业链中的位置，并高亮标注。

**持仓股数据来源**：用户输入（6只股票代码）

**预置持仓股**：

| 股票名称 | 代码 | 所属行业 |
|---------|------|---------|
| 迪安诊断 | 300244 | 脑机接口（医疗器械方向） |
| 数据港 | 603881 | 算力（数据中心） |
| 中文在线 | 300364 | 算力（AI应用/内容） |
| 宏景科技 | 301396 | 算力（AIoT/智能硬件） |
| 创新医疗 | 002173 | 脑机接口（医疗器械） |
| 西藏旅游 | 600749 | 航空航天（运营端） |

**高亮规则**：
- 持仓股所在节点：节点边框变为金色 + 持仓股名称标注
- 持仓股所在企业卡片：卡片左上角显示"📌 持仓"标签
- 持仓股的上游节点：标注"↗ 上游供应"
- 持仓股的下游客户（若已上市）：标注"↘ 下游客房"

**预警规则**：
- 若持仓股在实体清单上：节点显示红色警报 + 提示"持仓风险提示：该公司在实体清单中"
- 若持仓股的**直接上游节点**（`parent_nodes` 中的节点，仅限一跳）的 `supply_level = risky`：节点显示黄色警报 + 提示"上游断供预警：[节点名] 存在断供风险"
  - 不向上递归（即上游的上游不触发预警）
  - 同一持仓股有多个直接上游断供时，全部列出

**"↘ 下游客房"文字修正**：应为"↘ 下游客户"（原文笔误）

**用户交互**：
- 用户可手动添加/删除/修改持仓股票代码
- 持仓数据存储在本地（localStorage）

### 3.13 FR-012 时间轴回溯

**功能描述**：支持查看历史某一时间点的产业链快照。

**历史数据来源**：
- 每次用户点击「更新数据」按钮完成更新后，系统自动将当前完整数据存档为一个带时间戳的版本快照（存入本地 IndexedDB）
- 快照内容与当前数据结构完全一致，不依赖外部历史数据库
- V1.0 上线时预置三个手工整理的初始快照：2024年1月 / 2025年1月 / 2026年5月，数据完整性以实际整理情况为准，缺失字段标注"—"

**时间版本**：至少支持 2024年1月 / 2025年1月 / 2026年5月（预置）+ 此后每次更新自动存档

**回溯内容**：
- 当时的产业链节点结构
- 当时的国产替代率数据
- 当时的TOP5企业（按快照时的录入数据，不重新排序）
- 关键事件标注（如"2024年：英伟达H100断供"，人工录入）

**交互规格**：
- 时间轴滑块位于页面底部，刻度为已存档的版本时间点
- 点击（或拖动）刻度切换历史版本
- 历史版本数据不足时标注"该版本数据不完整（部分字段缺失）"
- 历史视图模式下顶部显示醒目提示条"当前查看：[版本时间] 历史快照"

## 4. 接口需求

### 4.0 数据流向总览

```
外部数据源（EXT-001~006）
        ↓  [自动抓取 / 人工录入]
  后端采集脚本（用户手动触发「更新数据」）
        ↓  [写入]
  本地数据文件（JSON / SQLite）← 产业链核心数据
        ↓  [读取]
  FastAPI 后端（/api/industries, /api/nodes, /api/companies）
        ↓  [HTTP 请求]
  前端页面（INT-001~004 调用后端 API）
        ↓  [读/写]
  浏览器本地存储
    ├── localStorage：持仓股代码（INT-006）
    └── IndexedDB：历史快照版本（FR-012）
```

> **说明**：产业链结构数据统一由后端管理，不直接内嵌前端静态资源（当前 V1.0 开发阶段暂以内嵌 JSON 实现，接口形态与上述一致，后续接后端只需改 fetch 调用地址）。

### 4.1 内部接口

| 接口编号 | 说明 | 调用方 | 提供方 | 备注 |
|---------|------|-------|-------|------|
| INT-001 | 获取行业列表 | 前端 | 后端 API | `GET /api/industries` |
| INT-002 | 获取某行业产业链结构 | 前端 | 后端 API | `GET /api/industries/{id}/nodes` |
| INT-003 | 获取某节点详情 | 前端 | 后端 API | `GET /api/nodes/{id}` |
| INT-004 | 获取某企业详细信息 | 前端 | 后端 API | `GET /api/companies/{code}` |
| INT-005 | 导出视图为图片 | 前端 | 渲染层（浏览器） | 使用 html2canvas，纯前端 |
| INT-006 | 持仓股数据存取 | 前端 | localStorage | 无需后端，纯前端 |
| INT-007 | 历史快照存取 | 前端 | IndexedDB | 每次更新完成后自动存档 |

### 4.2 外部接口

| 接口编号 | 说明 | 数据源 | 频率 | 采集方式 |
|---------|------|-------|------|---------|
| EXT-001 | 上市公司财务数据 | 年报/半年报/季报（PDF/HTML） | 季频 | **自动抓取（年报 PDF 解析）** |
| EXT-002 | 专利数据 | 国家知识产权局公开数据库 | 月频 | 自动抓取 |
| EXT-003 | 实体清单数据 | BIS官网 | 周频 | 自动抓取 |
| EXT-004 | 专精特新名单 | 工信部 | 年频 | 自动抓取 |
| EXT-005 | 原材料价格数据 | WIND/同花顺/生意社 | 周频 | 自动抓取 |
| EXT-006 | 国产替代率数据 | 工信部/行业协会报告 | 半年频 | **人工整理后录入**（无结构化 API） |
| EXT-007 | 产业链节点/企业归属 | 公司公告 + 研报 | 半年频 | **人工核对后录入**（无法自动化） |

### 4.3 数据存储

| 存储类型 | 内容 | 介质 | 读写方 |
|---------|------|------|-------|
| 后端本地文件 | 产业链结构 + 企业数据（权威层） | JSON / SQLite | 后端采集脚本写入，FastAPI 读取 |
| 浏览器 localStorage | 持仓股代码列表 | localStorage | 前端读写，无需后端 |
| 浏览器 IndexedDB | 历史版本快照（FR-012） | IndexedDB | 前端在每次更新完成后写入 |

### 5.2 数据完整性规则

| 规则编号 | 规则内容 | 违约处理 |
|---------|---------|---------|

## 6. 非功能性需求

### 6.1 性能需求

| 指标 | 要求 |
|------|------|
| 页面首次加载时间 | ≤ 3秒（3G网络环境） |
| 行业切换响应时间 | ≤ 1秒 |
| 节点详情展开时间 | ≤ 0.5秒 |
| 桑基图渲染时间 | ≤ 2秒（100节点以内） |
| 图片导出时间 | ≤ 3秒 |

### 6.2 兼容性需求

| 环境 | 要求 |
|------|------|
| 桌面浏览器 | Chrome ≥ 90, Firefox ≥ 88, Safari ≥ 14, Edge ≥ 90 |
| 屏幕分辨率 | 桌面 ≥ 1280×720 |

> ℹ️ 本产品不支持移动端，仅限桌面端访问。

### 6.3 数据质量需求

| 维度 | 要求 |
|------|------|
| 准确性 | 财务数据必须来自上市公司官方公告（年报/半年报/季报），估算数据须标注置信度级别 |
| 时效性 | 财务数据滞后不超过一个季度，原材料价格数据滞后不超过一周 |
| 完整性 | 每个行业至少覆盖上中下游各3个节点，每个节点至少对应1家上市公司 |
| 一致性 | 同一字段在不同来源中数值差异超过5%时，须标注"数据差异说明" |

#### 6.3.1 置信度分级可视化规范

置信度分三级，用于标注产业链节点和企业卡片中的估算/参考类数据：

| 级别 | 标识 | 颜色 | 含义 | 典型数据 |
|------|------|------|------|---------|
| ① 官方 | 无特殊标注（默认） | — | 来自上市公司官方公告、政府文件 | 年报财务数据、BIS实体清单、工信部名单 |
| ② 权威 | `※` 上标小字 | 灰色文字 | 来自行业协会、权威研究机构 | 工信部/半导体协会的国产替代率报告 |
| ③ 参考 | `~` 前缀 + 斜体 | 橙色文字 | 来自研报估算、非官方渠道 | 研报中的市场规模估算、价格区间 |

**展示位置**：
- 节点详情面板 → 供需格局区块：国产替代率数值右侧显示对应标识
- 企业卡片 → 财务数据行：数值右侧显示对应标识
- 鼠标悬停标识时，显示 tooltip："数据来源：[来源名称]，更新时间：[日期]"

### 6.4 安全需求

- 无用户登录，不涉及用户隐私数据
- 持仓股数据存储于用户本地浏览器（localStorage），不传输至服务器
- 外部数据接口需设置防爬虫措施（请求频率限制）

### 6.5 可维护性需求

| 维度 | 要求 |
|------|------|
| 模块解耦 | 产业链结构数据与渲染逻辑解耦，支持独立更新数据文件 |
| 扩展性 | 数据层预留接口，支持未来增加第四个行业（结构不变） |
| 可追溯 | 数据来源须在详情面板中标注（官方/权威/参考三级） |
