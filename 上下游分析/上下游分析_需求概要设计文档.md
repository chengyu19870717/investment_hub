## 三、核心功能需求（已确认）

### 3.1 产业链分层结构

每个行业分三层：

```
上游（原材料/元器件）
    ↓
中游（核心产品/核心工艺）
    ↓
下游（终端产品/运营维护）
```

每层需标注：
- **核心产品名称**
- **核心工艺/工序**
- **对应头部上市企业 TOP 5**（不足5家照实显示）

### 3.2 依赖关系拉通

- 端到端贯穿：原材料 → 最终产品 → 运营维护
- 可视化展示节点间依赖关系（谁卡谁/谁依赖谁）

### 3.3 专利标注

- 持有核心专利的企业用特殊标识标注（如 🔬 标记）
- 标注专利类型（发明专利/实用新型）

## 四、补充功能需求（采纳全部）

> 优先级说明：**P0** = V1.0 必须有 / **P1** = V1.1 跟进 / **P2** = V1.2 以后

### 4.1 供需格局标注【P0】

每个节点标注：
- **国产替代率**（当前百分比）
- **产能瓶颈等级**：宽松 / 偏紧 / 断供风险
- **价格走势**：核心原材料当前价格（如H100 GPU/碳纤维/稀土价格）

### 4.2 上市公司财务纯度【P0】

每家企业标注：
- 该业务占**营收比例**（主业/蹭概念）
- **毛利率/净利率**（护城河）
- **客户集中度**（是否依赖单一甲方）

### 4.3 制裁/政策风险标注【P1】

- 是否在**美国实体清单**
- 是否涉及**国产替代**政策受益
- **专精特新/小巨人**资质标注
- **国家大基金持仓**情况

### 4.4 持仓股穿透高亮【P1】

- 自动识别6只持仓股（迪安诊断、数据港、中文在线、宏景科技、创新医疗、西藏旅游）在产业链中的位置
- 标注持仓股的上游供应商和下游客户（已上市部分）
- 持仓股遭遇制裁/断供风险时触发预警标签

### 4.5 数据维护机制【P0】

**维护责任方：程钰本人（手工触发）**

- **触发方式**：用户点击页面内「更新数据」按钮，全量刷新
- **主体结构**（产业链节点/企业归属）：半年更新一次，人工核对后录入
- **事件/价格层**（制裁/扩产/价格波动）：周频，手工触发更新
- **上市公司财务数据**：季频，自动解析年报/半年报 PDF
- **制裁名单**：周频，自动抓取 BIS 官网
- 数据来源分级标注：①官方（年报/公告）②权威（工信部/行业协会）③参考（研报估算）

### 4.6 展示形式【P0 树状图 / P2 桑基图】

- **主视图（P0）**：树状层级图（横向：左→右=上游→下游，纵向：按规模/重要性排列）
- **辅助视图（P2）**：桑基图（用于展示流量/依赖关系方向）
- 支持切换：树状图 ↔ 桑基图

### 4.7 时间轴回溯【P2】

- 查看历史某时间点的产业链快照
- 对比2024年 vs 2025年 vs 当前状态变化
- 标注关键节点变化事件（如某环节国产替代率提升时间点）
- **历史数据来源**：每次手工更新时由系统自动存档当前版本（版本化快照），不依赖外部历史数据库

### 4.8 移动端适配

> ❌ 已移除。本产品仅支持 Web 桌面端，不做移动端适配。

## 五、上市公司数据字段定义

| 字段 | 说明 | 数据来源 | 更新频率 | 维护方式 |
|------|------|---------|---------|---------|
| 公司名称 | 全称 | — | — | 初始录入，一般不变 |
| 股票代码 | 上交所/深交所 | — | — | 初始录入，一般不变 |
| 核心产品/工艺 | 所在节点 | 公司公告 | 半年 | **人工核对后手动录入** |
| 营收占比 | 该业务占总营收% | 年报/半年报 | 季频 | **自动解析年报 PDF** |
| 毛利率 | 该业务毛利率 | 年报 | 季频 | **自动解析年报 PDF** |
| 客户集中度 | 前五大客户占比 | 年报 | 年频 | **自动解析年报 PDF** |
| 专利数量 | 核心专利数量 | 国家知识产权局 | 季频 | **自动抓取知识产权局** |
| 国产替代率 | 所在环节国产替代% | 工信部/行业协会 | 半年 | **人工整理后录入** |
| 制裁状态 | 是否在实体清单 | 美国商务部BIS | 周频 | **自动抓取 BIS 官网** |
| 资质标注 | 专精特新/小巨人等 | 工信部 | 年频 | **自动抓取工信部名单** |

## 六、界面层级设计（初步）

```
首页
├── 行业切换标签（算力 | 脑机接口 | 航空航天）
├── 产业链树状图（主视图）
│   ├── 上游层（原材料节点组）
│   ├── 中游层（核心产品节点组）
│   └── 下游层（终端产品节点组）
├── 节点详情面板（点击展开）
│   ├── 产品/工艺说明
│   ├── TOP5企业列表（含财务纯度+专利标注）
│   ├── 供需格局（国产替代率/价格）
│   └── 政策风险（制裁/资质）
├── 持仓股高亮标签
├── 视图切换（树状图 ↔ 桑基图）
└── 时间轴滑块（历史快照）

底部导航
├── 导出图片
└── 全屏模式
```

## 七、数据源清单

| 数据类型 | 来源 |
|---------|------|
| 上市公司财务数据 | 年报/半年报/季报 |
| 产业链结构 | 公司公告 + 工信部文件 + 行业协会报告 + 研报 |
| 专利数据 | 国家知识产权局（WIPO）公开数据库 |
| 国产替代率 | 工信部/中国半导体行业协会/碳纤维协会 |
| 制裁名单 | 美国商务部工业与安全局（BIS）实体清单 |
| 专精特新名单 | 工信部 |
| 原材料价格 | WIND/同花顺/生意社 |
| 持仓股数据 | 用户输入（6只股票代码） |

| 需求 | 说明 |
